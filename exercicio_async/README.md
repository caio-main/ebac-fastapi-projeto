# Exercício: API Assíncrona com FastAPI

Este projeto é uma atividade prática focada na implementação de endpoints assíncronos (`async def` e `await`) utilizando FastAPI. A API gerencia um catálogo de livros em memória, simulando chamadas de I/O não-bloqueantes.

## 🛠️ Tecnologias Utilizadas
* Python 3.x
* FastAPI
* Uvicorn (Servidor ASGI)
* Pydantic (Modelagem e validação de dados)

## 🚀 Como instalar e executar

1. **Instale as dependências necessárias:**
   Abra o terminal na pasta do projeto e execute:
   ```bash
   pip install fastapi uvicorn
